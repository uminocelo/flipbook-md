# Issue 4.1.1: Load templates.yml

**Branch:** [4 — Saved templates](../../README.md)
**Milestone:** [4.1 — Deck templates](README.md)
**Description:** Read an optional `templates.yml` from the deck root. Each key is a template name. The value is one content region on the built-in 3×3 grid. A slide may then use `<!-- template: quote -->`.
**Tests:** required

## Tasks
- [x] Task 4.1.1.1: Parse `templates.yml` into named placements
  **Acceptance criteria:**
  - A missing `templates.yml` leaves the built-in templates unchanged
  - A key maps to `column`, `row`, `width`, `height`, and `align`
  - `column` and `row` start at 1. `width` and `height` are at least 1. `column + width` and `row + height` are at most 4
  - `align` is `start`, `center`, or `end`
  - The name matches `[a-z][a-z0-9-]*` and is not `flow`, `cover`, or `summary`
  - A bad name, a bad number, a bad `align`, or a non-object file throws and names `templates.yml`
  - A slide template named in the file loads. Any other unknown name still fails the load
- [x] Task 4.1.1.2: Accept those names on a blueprint type
  **Acceptance criteria:**
  - A blueprint type may set `template` to a name defined in the same deck's `templates.yml`
  - A type template that is neither a built-in nor a deck name throws and names `blueprint.yml`
  - Built-in checks from Branch 2 still pass when `templates.yml` is absent
- [x] Task 4.1.1.3: Write tests for deck templates
  **Acceptance criteria:**
  - Tests cover a missing file, a valid `quote` placement, a reserved name, a cell outside the 3×3 grid, a slide that uses `quote`, and a blueprint type that requires `quote`
  - `npm test` passes

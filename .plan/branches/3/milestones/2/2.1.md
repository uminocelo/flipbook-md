# Issue 3.2.1: Teach explain-deck the blueprint contract

**Branch:** [3 — Authoring](../../README.md)
**Milestone:** [3.2 — Generator contract](README.md)
**Description:** Update `~/.grok/skills/explain-deck/SKILL.md` so a generated directory deck satisfies a blueprint. Do not add a model call or a prose generator to `src/` or `bin/`.
**Tests:** not applicable — skill prose outside the package. The example deck test in [3.1.2](../1/1.2.md) is the executable contract.

## Tasks
- [x] Task 3.2.1.1: Require typed filenames and template comments in explain-deck
  **Acceptance criteria:**
  - The skill tells the agent to name directory slides `slides/NN_<type>.slide.md`, including `01_cover.slide.md` and a final `NN_conclusion.slide.md`
  - The cover slide includes `<!-- template: cover -->` and the conclusion slide includes `<!-- template: summary -->`
  - The skill still writes `presentation.yml` and a matching `*.slide.md`
  - The single-file deck repeats `<!-- type: ... -->` on each slide
- [x] Task 3.2.1.2: Require a blueprint and a check after writing
  **Acceptance criteria:**
  - The skill writes `blueprint.yml` next to `presentation.yml`
  - The conclusion type allows only `heading` and `paragraph` and sets `max_chars: 250`
  - The skill tells the agent to run `flipbook check` on the deck directory and to fix violations before finishing
  - The skill does not ask Flipbook to invent the slide copy
- [x] Task 3.2.1.3: Ask for a default, saved, or new template before writing
  **Acceptance criteria:**
  - The skill asks in the same step as the theme question and waits
  - The choices are the built-in `flow`, `cover`, and `summary`; every `*.yml` file in `~/Documents/flipbook/templates/` by name; or a new placement
  - The saved list is omitted when that directory is missing
  - The skill does not ask again when the user already names a template
  - A saved or new template is copied into `<deck>/templates.yml`. A file that stays only in `~/Documents/flipbook/templates/` is not used at show time
  - A new placement is also written to `~/Documents/flipbook/templates/<name>.yml`
  - `flow`, `cover`, and `summary` remain available on slides either way
  - The skill does not edit `src/templates.js` and does not put the placement in `presentation.css`

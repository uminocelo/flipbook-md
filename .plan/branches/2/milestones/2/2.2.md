# Issue 2.2.2: Enforce content rules

**Branch:** [2 — Deck blueprint](../../README.md)
**Milestone:** [2.2 — Content rules and check](README.md)
**Description:** Apply the type's rules, then any override on the matching `pages` step. Also require the slide template to match the type. When the slide left the template unset, fill it from the type before `show` and `export` render.
**Tests:** required

## Tasks
- [ ] Task 2.2.2.1: Compare measured slides with type and page rules
  **Acceptance criteria:**
  - A `conclusion` type with `allow: [heading, paragraph]` and `max_chars: 250` accepts a heading plus paragraph at 250 characters
  - The same slide at 251 characters fails and the violation states the count and the maximum
  - A list, fence, image, blockquote, or table on that type fails and names the forbidden kind
  - `forbid` rejects a kind even when `allow` is omitted
  - A page-step `max_chars` replaces the type's `max_chars` for slides matched to that step
  - A slide whose `template` disagrees with the type's `template` fails
  - A slide with template `flow` because the author set nothing inherits the type's template on the loaded slide
- [ ] Task 2.2.2.2: Write tests for content rules
  **Acceptance criteria:**
  - Tests cover the 250-character conclusion, one character over, a list on a text-only type, a page-level override, a template mismatch, and template inheritance
  - `npm test` passes
